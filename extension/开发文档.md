# 任务：开发一个 Chrome 浏览器扩展插件，用于提取网页文章并导出为 Markdown 或 PDF

## 目标
制作一个 Chrome 插件（Manifest V3），能在绝大多数网站上：
1. 一键提取网页正文为干净的 Markdown 格式（可复制或下载 .md 文件）
2. 一键将正文导出为可搜索的文字型 PDF（非图片型）
3. 支持中文网页（知乎、掘金、微信公众号等）

---

## 技术栈（已确认可行，勿替换核心库）

- **Manifest Version**: 3（MV3）
- **正文提取**: Mozilla Readability.js（v0.5.0+，https://github.com/mozilla/readability）
- **HTML 转 Markdown**: Turndown.js（v7.1.3+，https://github.com/mixmark-io/turndown）
- **PDF 导出**: 注入 print CSS + window.print()（不要使用 jsPDF + html2canvas，后者生成图片型PDF，中文会乱码）
- **不需要**任何打包工具（webpack/vite），直接原生 JS + 手动引入 lib

## content_script.js 核心逻辑（需完整实现）

### 1. 正文提取函数
```javascript
function extractArticle() {
  const docClone = document.cloneNode(true);
  const reader = new Readability(docClone, {
    charThreshold: 20,       // 降低阈值以兼容中文短段落
    keepClasses: false       // 不保留 class，减少噪音
  });
  const article = reader.parse();

  if (!article || !article.content) {
    // 降级方案：按优先级查找正文容器
    const fallbackSelectors = [
      'article',
      '[role="main"]',
      '[class*="article-content"]',
      '[class*="post-content"]',
      '[class*="article-body"]',
      '[class*="content-body"]',
      '[class*="rich_media_content"]',  // 微信公众号
      '.notion-page-content',            // Notion
      'main'
    ];
    for (const sel of fallbackSelectors) {
      const el = document.querySelector(sel);
      if (el && el.innerText.trim().length > 200) {
        return {
          title: document.title,
          content: el.innerHTML,
          byline: '',
          siteName: location.hostname,
          excerpt: el.innerText.substring(0, 100)
        };
      }
    }
    // 最终兜底
    return {
      title: document.title,
      content: document.body.innerHTML,
      byline: '',
      siteName: location.hostname,
      excerpt: ''
    };
  }
  return article;
}
```

### 2. 转换为 Markdown 函数
```javascript
function articleToMarkdown(article) {
  const td = new TurndownService({
    headingStyle: 'atx',
    codeBlockStyle: 'fenced',
    bulletListMarker: '-',
    hr: '---'
  });

  // 插件：支持删除线
  td.addRule('strikethrough', {
    filter: ['del', 's'],
    replacement: (content) => `~~${content}~~`
  });

  // 插件：代码块处理（优先用 pre > code 结构提取语言）
  td.addRule('fencedCodeBlock', {
    filter: (node) => node.nodeName === 'PRE' && node.querySelector('code'),
    replacement: (content, node) => {
      const code = node.querySelector('code');
      const langClass = code?.className || '';
      const lang = langClass.match(/language-(\w+)/)?.[1] || 
                   langClass.match(/lang-(\w+)/)?.[1] || '';
      const codeText = code?.textContent || node.textContent;
      return `\n\`\`\`${lang}\n${codeText.trim()}\n\`\`\`\n`;
    }
  });

  // 将图片相对 URL 转为绝对 URL
  const baseUrl = location.href;
  td.addRule('absoluteImages', {
    filter: 'img',
    replacement: (content, node) => {
      let src = node.getAttribute('src') || '';
      let alt = node.getAttribute('alt') || '';
      if (src && !src.startsWith('http') && !src.startsWith('data:')) {
        try { src = new URL(src, baseUrl).href; } catch(e) {}
      }
      return src ? `![${alt}](${src})` : '';
    }
  });

  // 生成带元数据的 Markdown
  const meta = [
    `# ${article.title}`,
    article.byline ? `> 作者：${article.byline}` : '',
    article.siteName ? `> 来源：${article.siteName}` : '',
    `> 原文：${location.href}`,
    `> 提取时间：${new Date().toLocaleString('zh-CN')}`,
    '',
    '---',
    ''
  ].filter(Boolean).join('\n');

  return meta + td.turndown(article.content);
}
```

### 3. PDF 导出函数（文字型 PDF，支持中文）
```javascript
function exportToPDF(article) {
  // 注入一个干净的打印专用 iframe
  const iframe = document.createElement('iframe');
  iframe.style.cssText = 'position:fixed;top:-9999px;left:-9999px;width:210mm;border:none;';
  document.body.appendChild(iframe);

  const printDoc = iframe.contentDocument || iframe.contentWindow.document;

  // 构建干净的 HTML，只保留正文
  printDoc.open();
  printDoc.write(`
    <!DOCTYPE html>
    <html lang="zh">
    <head>
      <meta charset="UTF-8">
      <title>${article.title}</title>
      <style>
        @page { margin: 2cm; size: A4; }
        * { box-sizing: border-box; }
        body {
          font-family: "PingFang SC", "Noto Sans SC", "Microsoft YaHei", sans-serif;
          font-size: 14px;
          line-height: 1.8;
          color: #333;
          max-width: 100%;
          word-break: break-word;
        }
        h1 { font-size: 22px; margin-bottom: 8px; }
        h2 { font-size: 18px; }
        h3 { font-size: 16px; }
        img { max-width: 100%; height: auto; page-break-inside: avoid; }
        pre, code {
          font-family: "Courier New", monospace;
          background: #f5f5f5;
          border-radius: 4px;
          font-size: 12px;
        }
        pre { padding: 12px; overflow-wrap: break-word; white-space: pre-wrap; page-break-inside: avoid; }
        code { padding: 2px 4px; }
        blockquote { border-left: 4px solid #ddd; margin: 0; padding-left: 16px; color: #666; }
        a { color: #0066cc; text-decoration: underline; }
        table { border-collapse: collapse; width: 100%; page-break-inside: avoid; }
        td, th { border: 1px solid #ddd; padding: 6px 10px; }
        .article-meta { color: #888; font-size: 12px; margin-bottom: 20px; border-bottom: 1px solid #eee; padding-bottom: 12px; }
      </style>
    </head>
    <body>
      <div class="article-meta">
        <div>来源：${article.siteName || location.hostname} | 原文：${location.href}</div>
      </div>
      <h1>${article.title}</h1>
      ${article.content}
    </body>
    </html>
  `);
  printDoc.close();

  // 等待渲染完成再触发打印
  iframe.contentWindow.onload = () => {
    setTimeout(() => {
      iframe.contentWindow.print();
      setTimeout(() => document.body.removeChild(iframe), 1000);
    }, 300);
  };
}
```

### 4. 消息监听（接收 popup 指令）
```javascript
chrome.runtime.onMessage.addListener((request, sender, sendResponse) => {
  if (request.action === 'extract') {
    try {
      const article = extractArticle();
      const markdown = articleToMarkdown(article);
      sendResponse({ 
        success: true, 
        markdown, 
        title: article.title,
        excerpt: article.excerpt || ''
      });
    } catch (e) {
      sendResponse({ success: false, error: e.message });
    }
  } else if (request.action === 'exportPDF') {
    try {
      const article = extractArticle();
      exportToPDF(article);
      sendResponse({ success: true });
    } catch (e) {
      sendResponse({ success: false, error: e.message });
    }
  }
  return true; // 保持异步通道开启
});
```

## popup.html 规格

弹窗尺寸 320×400px，包含以下元素（用简洁现代的 UI 风格实现）：

1. 顶部：插件名称 + 当前页面标题（截断显示）
2. 中间：文章摘要预览（2-3行，灰色文字）
3. 底部操作区，4个按钮：
   - 「📋 复制 Markdown」— 复制到剪贴板
   - 「⬇ 下载 .md 文件」— 下载文件
   - 「🖨 导出 PDF」— 调用 PDF 导出
   - 「👁 预览正文」— 在新标签页展示提取后的干净正文（可选，优先级最低）
4. 底部状态栏：显示操作结果（成功/失败提示）

## popup.js 核心逻辑

1. 页面加载时，自动向 content_script 发送 `extract` 消息，获取标题和摘要用于展示
2. 「复制 Markdown」：发送 `extract` 消息，获取 markdown 内容后写入剪贴板（使用 `navigator.clipboard.writeText`）
3. 「下载 .md 文件」：发送 `extract` 消息，用 `chrome.downloads.download` 下载 Blob URL，文件名为 `{清理后的标题}.md`
4. 「导出 PDF」：发送 `exportPDF` 消息给 content_script 执行

文件名清理函数：
```javascript
function sanitizeFilename(title) {
  return title
    .replace(/[\\/:*?"<>|]/g, '_')
    .replace(/\s+/g, '_')
    .substring(0, 80) + '.md';
}
```

## 已知问题及处理方式（必须在代码中处理）

| 问题 | 处理方式 |
|---|---|
| 动态渲染的 SPA 页面（知乎单页应用） | content_script 设置 `run_at: document_idle` + 降级 fallback selector |
| 微信公众号正文在 `.rich_media_content` | 已加入 fallback selector 列表 |
| 图片用 lazyload（src 为占位符）| 尝试读取 `data-src` / `data-original` 作为备用 |
| PDF 打印弹出系统对话框 | 这是预期行为，用户在对话框中选「另存为PDF」即可 |
| Readability 提取失败（返回 null） | 已有 fallback 机制，不会崩溃 |
| 某些页面 CSP 阻止 content_script | 无法绕过，在 popup 显示友好错误提示即可 |

## 实现要求

1. 所有代码用原生 ES6+ JS，无需框架
2. Readability.js 和 Turndown.js 使用本地 lib 文件，不从 CDN 加载（CSP 限制）
3. 不发送任何数据到外部服务器，所有处理在本地完成
4. 代码需有中文注释
5. 提供完整的所有文件，可以直接加载为未打包扩展（chrome://extensions → 加载已解压的扩展程序）
